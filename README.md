# Basketball Motion Lab

中学校のバスケットボール部で、シュート映像を見ながら動きを振り返るためのブラウザアプリです。`index.html` をそのまま静的ホスティングできます。ビルドは不要です。

## 使い方

1. HTTPS上のページを開き、「バスケットボール」を選びます。全身が映った短いシュート動画を選ぶか、カメラで撮影します。
2. シュートする腕を選び、「動画を自動分析」を押します。黄色は推定した骨格、緑は身体中心の代理点と開始位置からの見かけの移動です。
3. 肘伸展ピークとその前後から3枚を選びます。ボールを検出していないため、構え・リリース・フォロースルーはあくまで候補です。動画でも場面を確認してください。
4. 専門版では範囲を指定して再解析できます。成功・失敗はそれぞれ動画を読み込み解析した後、手動で登録してください。登録はページを閉じると消えます。CSVを保存できます。

カメラを固定し、十分な明るさで、選手の全身とシュートする腕が見える向きから撮影してください。動画が長いと分析に時間がかかります。分析は中止できます。

## GitHub Pages

リポジトリのルートに `index.html` とこのREADMEを置き、GitHubの **Settings → Pages → Build and deployment** でブランチとルートを指定してください。公開URLのHTTPSでカメラを利用できます。ブラウザのカメラ許可が必要です。端末やブラウザが対応しない動画形式は再生できません。

ローカル確認は、このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。

## データと限界

- 動画の推論はブラウザ内で行い、アプリは動画をサーバーに送信しません。MediaPipeのライブラリとモデルはjsDelivrから取得するため、ネット接続が必要で、取得先に通常の接続情報が渡ります。オフライン動作は保証しません。
- 動画は自動保存されません。手動記録はブラウザのlocalStorageに保存され、共有端末の同じブラウザから見える場合があります。利用後の削除や学校の運用ルールを確認してください。
- 姿勢、角度、画像上の身体中心は2Dの推定です。真の重心や3Dの関節角度ではなく、撮影角度、遮蔽、ブレ、複数人、画質の影響を受けます。
- 実寸校正はカメラに対して同じ平面上でのみ近似として扱えます。校正なしの移動量と速度は画面幅を基準にした割合です。画面内の移動は奥行きやカメラの動きでも変化します。
- 鉛直支持力は任意の体重と画像上の加速度から、接地が続く仮定で計算した理論モデルであり、実測床反力ではありません。踏切・着地の衝撃や接地状態は測れません。ノイズの影響が大きいため指導上の参考に限定してください。
- アドバイスと成功・失敗の差は練習の仮説であり、診断や原因の断定ではありません。大人と一緒に複数回の映像を確認してください。

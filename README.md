# Basketball Motion Lab

中学校のバスケットボール部でシュートフォームを振り返るためのブラウザアプリです。`index.html` と `vendor/pose/` を一緒に静的ホスティングできます。ビルドは不要です。

## 使い方

1. 動画を選ぶか、その場でカメラ撮影します。シュートする腕が見える向きから、ボールと全身が入るようにカメラを固定してください。
2. 動画を確認し、シュートする腕を選んで「動画を自動分析」を押します。簡易版は1回につき最大8秒です。長い動画では開始と終了を指定してください。ボールが手を離れた場面を見つけたら、その時刻も手動で指定できます。
3. 結果から「軌跡を見る」を押します。手首・肩・腰の動きを色で確認し、前後の骨格画像と練習のヒントを見比べます。離れた時刻を指定しないときは腕の姿勢から候補を選びます。
4. 「動画とボールを手動で確認」は、骨格分析の前や分析できなかったときにも使えます。止めた画像でボールをタップすると、記録した点を結ぶ線が表示されます。点は動画を入れ替えるまで残ります。
5. 専門版では分析範囲と間隔を指定し、角度グラフやCSV、成功と失敗の比較を使えます。比較に使うシュートの成否は手動で登録します。

初回の骨格分析ではAIモデルをダウンロードします。

## GitHub Pages

リポジトリのルートに `index.html`、`vendor/pose/`、`.nojekyll` を置き、GitHubの **Settings → Pages → Build and deployment** でブランチとルートを指定してください。公開URLのHTTPSでカメラを利用できます。ブラウザのカメラ許可が必要です。端末やブラウザが対応しない動画形式は再生できません。

ローカル確認は、このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。

## データと限界

- 動画の推論はブラウザ内で行い、アプリは動画をサーバーに送信しません。MediaPipe Pose 0.5.1675469404のライブラリとモデルはアプリと同じ公開先から読み込みます。オフライン動作は保証しません。
- 動画は自動保存されません。手動記録はブラウザのlocalStorageに保存され、共有端末の同じブラウザから見える場合があります。利用後の削除や学校の運用ルールを確認してください。
- 骨盤の代理点は左右の股関節の推定点の中点です。真の骨盤位置や3D回旋角度ではありません。専門版の移動量やCSVにもこの代理点を出力します。
- 姿勢、角度、画像上の身体中心は2Dの推定です。真の重心や3Dの関節角度ではなく、撮影角度、遮蔽、ブレ、複数人、画質の影響を受けます。
- 実寸校正はカメラに対して同じ平面上でのみ近似として扱えます。校正なしの移動量と速度は画面幅を基準にした割合です。画面内の移動は奥行きやカメラの動きでも変化します。
- 鉛直支持力は任意の体重と画像上の加速度から、接地が続く仮定で計算した理論モデルであり、実測床反力ではありません。踏切・着地の衝撃や接地状態は測れません。ノイズの影響が大きいため指導上の参考に限定してください。
- アドバイスと成功・失敗の差は練習の仮説であり、診断や原因の断定ではありません。大人と一緒に複数回の映像を確認してください。
